# biological---dataset-selection
Task 1: Biological Dataset Selection

1. Dataset Title

Gene Expression Dataset for Lung Adenocarcinoma

2. Dataset Source

NCBI Gene Expression Omnibus (GEO)

Dataset ID: GSE10072

Official Dataset Link:
https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE10072

3. Organism and Data Type

Organism: Homo sapiens (Human)

Data Type: Gene expression profiling using microarray technology.

4. Dataset Size

The dataset contains 107 samples:

- 58 lung adenocarcinoma tumour samples
- 49 non-tumour lung samples

5. Research Question

Which genes show different expression levels between lung adenocarcinoma tumour tissue and non-tumour lung tissue? How might smoking status be associated with these gene-expression patterns?

6. Purpose of the Dataset

This dataset can help researchers explore differences in gene-expression patterns between tumour and non-tumour lung tissues. It can also support further investigation into possible associations between smoking and gene expression.

7. Proposed Analysis

1. Download the publicly available dataset from NCBI GEO.
2. Review the sample information and gene-expression data.
3. Compare gene-expression patterns between tumour and non-tumour samples.
4. Identify genes with potentially different expression levels using appropriate statistical methods.
5. Present observations using tables and charts.

8. Tools

Excel, Python, or R can be used for data inspection and analysis.

9. Conclusion

GSE10072 is a publicly accessible biological dataset suitable for learning bioinformatics and gene-expression analysis. It provides an opportunity to explore lung cancer-related gene-expression patterns without performing laboratory experiments.
